# Admin Dashboard

A static admin dashboard layout built as part of [The Odin Project](https://www.theodinproject.com/) curriculum.

🔗 **Live demo:** https://kajrir.github.io/AdminDashboard/

## Features
- Sidebar navigation, header with search and profile, and a main content area
- Project cards and "trending" / announcement panels
- Inline SVG icons

## Built with
- HTML
- CSS Grid and Flexbox (`grid-template-areas` for the page layout)
- normalize.css

## What I learned
- Combining CSS Grid for the overall page with Flexbox inside components
- Building a realistic, information-dense layout from a design
